This newspaper front page presents the world news of Tuesday, 24 November 2026, with the Hormuz tanker attack as the lead and five illustrated briefs spanning Saudi Arabia, global markets, climate diplomacy, Nepal, and international law. Run `python3 main.py` to copy the shipped image to `MAKEFUN_OUTPUT_DIR` (or `/output`); `python3 compose.py` rebuilds it using Pillow 10.2.0, DejaVu fonts, and the supplied text-free illustrations.
